# 🏖️ Summer of Making Analytics

A comprehensive data analytics project for the [Summer of Making](https://summer.hackclub.com/) program, providing insights into user behavior, project trends, engagement patterns, and community dynamics.

## Overview

This project scrapes, processes, and analyzes data from the Summer of Making platform to generate detailed analytics and visualizations covering:

- **User Analytics**: Registration trends, coding activity, badge distribution, and engagement metrics
- **Project Analytics**: Category distributions, development patterns, and popularity metrics  
- **Devlog Analytics**: Content analysis, engagement tracking, and posting patterns
- **Comment Analytics**: Community interaction analysis and engagement insights
- **Follower Analytics**: Project following patterns and community connections
- **Badge Analytics**: Achievement distribution and user recognition patterns

## Running this project

### Prerequisites

- **Node.js**
- **Python** 
- **Jupyter Notebooks** 

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/AjayAntoIsDev/SoM-Analytics
   cd SoM-Analytics
   ```

2. **Install Node.js dependencies**:
   ```bash
   npm install
   ```

3. **Install Python dependencies**:
   ```bash
   pip install pandas plotly wordcloud matplotlib numpy kaleido pyarrow jupyter
   ```

### Usage

#### 1. Data Collection

Run the scrapers to collect data from Summer of Making:

```bash
npm run scrape --cookies="_journey_session=YOUR_SESSION_COOKIE" # Get it from your browser's developer tools
```

This will populate the `data/raw/` directory with JSON files containing the latest data.

#### 2. Data Analysis

Open and run the Jupyter notebooks in the `analytics/` directory:

```bash
cd analytics/
quarto preview
```

This will
- Load and clean the raw data
- Perform statistical analysis
- Generate visualizations
- Generate a web report with Quarto

#### 3. View Results

Analysis outputs are saved to `data/processed/[category]/`:
- **PNG files**: Charts and visualizations
- **index.json**: Structured analysis results and metadata
- **output/**: Web report generated by Quarto

## Technical Details

### Data Pipeline

1. **Collection**: Node.js scrapers fetch data from Summer of Making API
2. **Storage**: Raw data stored as JSON files in `data/raw/`
3. **Processing**: Python notebooks clean and transform data to Parquet format
4. **Analysis**: Statistical analysis and visualization generation
5. **Export**: Results exported as structured JSON and PNG visualizations

### Data Format

- **Raw Data**: JSON files with complete API responses
- **Processed Data**: Parquet files optimized for analysis
- **Analysis Output**: JSON indices with metadata and PNG visualizations

### Key Technologies

- **Data Collection**: Node.js, node-fetch
- **Data Processing**: Python, Pandas, PyArrow
- **Visualization**: Plotly, Matplotlib, WordCloud
- **Storage**: Parquet (columnar format for efficient analysis)
- **Analysis Environment**: Jupyter Notebooks
- **Documentation**: Quarto for generating web reports

## Data Schema

### Users Dataset
- User profiles, activity metrics, coding time, project counts, badge counts

### Projects Dataset  
- Project metadata, categories, development time, engagement metrics

### Devlogs Dataset
- Devlog content, timestamps, engagement data, project associations

### Comments Dataset
- Comment content, timestamps, user interactions, devlog associations

### Followers Dataset
- Following relationships between users and projects

### Badges Dataset
- Badge assignments, user achievements, recognition data
